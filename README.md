# AI - Лінго: Розумний AI-Перекладач

MVP сучасного веб-перекладача з мінімалістичним кастомним дизайном, що працює на базі великої мовної моделі Google Gemini. Проєкт створено в рамках практичної лабораторної роботи.

## 📋 Проблема та рішення
Проблема: Класичні онлайн-перекладачі часто перекладають слова занадто буквально, втрачаючи контекст, сленг, стійкі ідіоми або художнє забарвлення тексту.
Рішення: `AI - Лінго` використовує актуальну нейромережу `gemini-3.5-flash-lite`, яка розуміє живу мову, адаптує переклад під правила цільової мови та видає природний результат.

## 🚀 Що вміє MVP (Функціонал)
1. **Мультимовний переклад:** Підтримка основних європейських мов (Українська, Англійська, Німецька, Французька, Іспанська, Польська).
2. **Розумна обробка помилок та валідація:** Програма не надсилає порожні запити, попереджає користувача підказками та захищена від раптових збоїв серверів API.
3. **Копіювання в 1 клік:** Зручна вбудована кнопка для швидкого перенесення перекладу в буфер обмена.
4. **Історія сесії:** Локальне збереження всіх виконаних перекладів у бічному меню.

## 🛠 Технології
* **Мова програмування:** Python
* **Фреймворк UI:** Streamlit
* **Штучний інтелект:** Google GenAI SDK (модель `gemini-3.5-flash-lite`)

## ⚙️ Як запустити проєкт локально

1. Клонуйте репозиторій або збережіть файли проєкту.
2. Встановіть необхідні залежності у вашому терміналі:
   pip install streamlit google-genai
   pip install pyperclip
3. Отримайте безкоштовний API ключ у [Google AI Studio](https://aistudio.google.com/api-keys).
4. Задайте ключ у системних змінних оточення:
   * Для Windows (CMD): `set GEMINI_API_KEY=ваш_ключ`
   * Для Linux/macOS: `export GEMINI_API_KEY="ваш_ключ"`
5. Запустіть додаток Streamlit:
   python -m streamlit run app.py
